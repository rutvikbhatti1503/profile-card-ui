# 🚀 Responsive Profile Card UI

A modern and visually appealing **Profile Card UI** built using **HTML and CSS**.
This project focuses on responsive design, smooth hover effects, and glassmorphism styling to create a clean and interactive user interface.

---

## ✨ Features

* 👤 Clean and modern profile card design
* 🎯 Smooth hover animation effects
* 🌫️ Glassmorphism UI (blur + transparency)
* 🖼️ Image shadow effects using CSS filters
* 📱 Fully responsive (Mobile First approach)
* 🎨 Modern typography using Google Fonts
* ⚡ Smooth transitions and scaling effects

---

## 🛠️ Technologies Used

* HTML5
* CSS3 (Flexbox + Media Queries + Animations)
* Google Fonts (Jost, Bebas Neue)
